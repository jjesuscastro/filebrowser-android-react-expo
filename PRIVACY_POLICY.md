# Privacy Policy

Effective date: September 11, 2026

File Browser Native is an Android client for connecting to a FileBrowser Quantum server that you provide. This policy explains what information the app handles and how it is used.

## Information The App Handles

File Browser Native does not use an application-owned backend, analytics service, advertising SDK, or crash reporting service.

The app may handle the following information on your device:

- Server address you enter
- FileBrowser Quantum source name you enter
- Username you enter
- Authentication token returned by your FileBrowser Quantum server
- Password, only if you choose "Keep me signed in"
- File and folder names, paths, previews, and file contents served by your configured FileBrowser Quantum server
- App preferences, such as theme settings

## How Information Is Used

This information is used only to provide the app's file browsing features, including signing in, browsing folders, previewing files, uploading files, downloading files, creating folders, editing text files, deleting files, moving files, searching, and creating shares when supported by your server.

Network requests are sent directly between your device and the FileBrowser Quantum server address you configure. File Browser Native does not send your server address, credentials, tokens, files, or file metadata to an application-owned server.

## Local Storage

The configured server address and source name are stored in app preferences on your device.

Authentication tokens are stored using Android encrypted credential storage. If you enable "Keep me signed in," your username and password are also stored using encrypted credential storage so the app can sign in again if the server session expires.

Signing out removes the stored authentication token and saved credentials. Choosing "Use another server" removes the stored server address, source name, authentication token, and saved credentials.

## File Transfers

Uploads and downloads happen directly between your device and your configured FileBrowser Quantum server. Downloaded files may be saved through Android's download manager or temporary app cache, depending on the action you choose.

The app does not inspect uploaded or downloaded files for advertising, analytics, profiling, or resale.

## Third-Party Services

The app connects only to the FileBrowser Quantum server address that you configure. Your FileBrowser Quantum server may be operated by you, your organization, or another third party. The privacy practices of that server are controlled by its operator, not by File Browser Native.

The app is built with Expo and React Native libraries to provide app storage, secure credential storage, media preview, document picking, sharing, and file transfer functionality. These libraries run as part of the app and are not used by this app for advertising or analytics.

## Children's Privacy

File Browser Native is not directed to children. The app is intended for users who have access to a FileBrowser Quantum server.

## Security

The app supports HTTPS server addresses and warns before using an unencrypted HTTP connection. HTTP connections can expose credentials and file contents to other parties on the network. Use HTTPS whenever possible.

No method of storage or transmission is completely secure. You are responsible for configuring and securing the FileBrowser Quantum server you connect to.

## Data Deletion

You can delete locally stored authentication data by signing out. You can delete all locally stored server connection data by selecting "Use another server."

To delete files, accounts, logs, or other information stored on your FileBrowser Quantum server, contact or use the tools provided by that server's operator.

## Changes To This Policy

This privacy policy may be updated from time to time. Updates will be posted with a new effective date.
